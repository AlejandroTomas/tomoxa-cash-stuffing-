# tasks/

Una spec por tarea grande: qué se pidió, alcance, criterios de aceptación y
estado. Útil para dejar el encargo por escrito antes de ejecutarlo o para
retomarlo en otra sesión. Al terminar se borra (lo que valga como regla se
mueve a `../context/`).

  sobre, ver sus documentos y filtrarlos con escritura a mano.
